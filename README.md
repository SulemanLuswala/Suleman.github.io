# Suleman Luswala Portfolio

This portfolio is built from the uploaded Data Analyst CV.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `suleman-portfolio`.
2. Upload all files in this folder to the repository root.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/ (root)`.
5. Save.

The site includes the résumé PDF as `resume.pdf`, so the Résumé button works automatically.

Before publishing, verify the LinkedIn profile URL and any personal details.
